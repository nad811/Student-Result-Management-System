# Student Result Management System

A Python application for managing student academic records. The project stores student marks in CSV files, calculates totals and percentages, and provides a simple interface for maintaining result data.

## Features

- Add student records
- View students
- Delete records
- Calculate totals
- Calculate percentages
- CSV-based storage

## Project Structure

The application separates student management, validation, calculations, file handling, and menu operations into different modules for better readability and organization.
